# Disseny de Software – prácticas en Java

Prácticas de la asignatura **Disseny de Software** del Grado en Ingeniería Informática de la UAB (curso 2026-27). El foco de la asignatura es el diseño orientado a objetos: patrones de diseño, diagramas UML y código fácil de mantener y ampliar.

| Carpeta | Qué es | Conceptos |
|---|---|---|
| [`point-of-sale-mediator`](point-of-sale-mediator) | Interfaz Swing de un TPV para un bar, rediseñada para quitar el acoplamiento entre listeners | Patrón Mediator, Observer (listeners de Swing), Java Swing, UML |

La simulación de N cuerpos con versión paralela (también de esta asignatura) está en su propio repositorio: [nbody-simulacion-paralela-java](https://github.com/pau-tuson/nbody-simulacion-paralela-java).
